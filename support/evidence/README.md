# Evidence for the current configuration

Upload photographs, calibration certificates, measurements and other supporting
files here. Give files descriptive names and cite their exact file/page/photo
location in the workbook. For large datasets, record a stable archive location,
revision and checksum in the workbook instead.

The dated-checkpoint workflow copies this folder with the workbook and PDF.
Files referenced outside this folder are not collected automatically; ensure
the checkpoint includes the evidence or identifies its stable archive location.
